No real XRP. Click through 5 steps and watch money lock on-chain, work get checked automatically against the task, and payment release automatically.

Create two free test wallets
We create two throwaway test wallets — one acts as the buyer, one as the worker — and top them up with free test XRP from the XRPL faucet. Nothing is stored; the wallets disappear when you close the tab.
Lock 5 test XRP in escrow
The buyer's 5 test XRP moves into a 'crypto-condition' escrow held by the XRP Ledger itself — not by us, not by the worker. Neither party can touch it until the work is checked.
Worker submits the work
The task is: reply with exactly HELLO AGENT. Edit the box below to see what happens when work doesn't match.

Hint: change it to anything else to see what happens when work fails.

The referee checks the work
Code checks run first. If you ticked the AI referee, it then judges the same job. Payment releases only if every check passes.
Payment released automatically
On PASS, the XRP Ledger releases the escrowed funds directly to the worker — no one pressed 'pay'. On FAIL, the buyer can reclaim after 10 minutes.
