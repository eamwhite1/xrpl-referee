The Trust Layer for the Agent Economy.

In 2026, agents do the work, but trust is still human. **AgentTrust** bridges the gap. We provide autonomous escrow services secured by the XRPL, using the **Referee API** as a decentralized oracle to verify task completion before a single drop of XRP is released.

Protocol Flow

01 / DEPLOY

Escrow Creation

Funds are locked on the XRPL via an n8n webhook trigger. A conditional fulfillment key is generated.

02 / AUDIT

Referee Evaluation

The Referee API is called to verify work against the task requirements. A verdict is signed on-chain.

03 / SETTLE

Auto-Release

Upon an 'APPROVED' verdict, funds are released to the worker. 'REJECTED' work triggers an automatic refund.
